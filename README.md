# 🎓 Santander Bootcamp 2025 - Ciência de Dados com Python

## 📝 Sobre o Programa
Este repositório contém o conjunto de projetos e desafios práticos desenvolvidos durante o bootcamp **Santander 2025**, promovido pela **DIO**. O programa focou na aplicação de Python para a resolução de problemas reais, cobrindo desde a automação de processos (ETL) até a análise estratégica de dados de mercado.

* **Instituição:** Digital Innovation One (DIO)
* **Carga Horária:** 63 horas
* **Conclusão:** 25 de Janeiro de 2026

---

## 🚀 Projetos em Destaque

Neste repositório, você encontrará as seguintes implementações:

### 1. 🤖 Pipeline de ETL com Simulação de IA
* **Foco:** Engenharia de Dados e Lógica de IA.
* **Descrição:** Desenvolvimento de um pipeline que extrai dados de clientes, utiliza lógica de geração de conteúdo para personalizar mensagens e exporta os dados enriquecidos.
* **Ferramentas:** Python, Pandas e lógica de amostragem aleatória.

### 2. 📊 Análise de Assinaturas Xbox Game Pass (2024)
* **Foco:** Data Analytics e Business Intelligence.
* **Descrição:** Análise exploratória de uma base de dados realística de assinaturas para identificar padrões de faturamento, taxas de renovação e adesão a produtos secundários (*cross-selling*).
* **Ferramentas:** Pandas e Visualização de Dados.

---

## 🛠️ Tecnologias e Habilidades Desenvolvidas
* **Linguagem Principal:** Python 3.x
* **Bibliotecas de Dados:** Pandas, NumPy, Matplotlib/Seaborn.
* **Conceitos de Engenharia:** ETL (Extract, Transform, Load), tratamento de tipos e automação.
* **Business Intelligence:** Definição de KPIs, análise de churn e métricas de receita.
